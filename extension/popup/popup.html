Downloads go straight here — they are assembled out of sight and appear only once complete, so a half-finished clip never reaches Dropbox or Premiere. The picker opens behind this popup; reopen it to confirm.

Downloads

Max grabs the highest resolution the video has (4K/8K). 1080p/720p stick to native H.264 — fastest, never converted.

YouTube ships 4K+ only as VP9/AV1, which Premiere can't read. This converts those files to high-bitrate H.264 with the Mac's hardware encoder. Turn off to keep the original codec.

Re-encodes at the cut so In/Out land exactly where you marked. Off = faster, cuts snap to keyframes (fine for rough B-roll).

Only for age/member-restricted videos. macOS will ask for keychain access the first time.

File names

Every grab prompts for a name first — Enter grabs, Esc cancels, blank keeps the automatic name.

Tokens: {title} {n} {id} {site} {start} {end} {date} {quality} — {n} counts grabs per video (part 1, 2, 3…)
